# Codex Ops 0.8.0 发布验收

[English](release-0.8.0.md)

状态：最终候选已测量，成本与严格质量门禁未通过。桌面仍启用0.7，尚无实验放行或安装。

## 功能变化

- 源码调查支持绝对根目录加问题，根据意图安排实现、测试、配置等来源，并通过一次有界 Rust 内核请求执行。复用已有 MIT 许可的 dsh-ops crate，没有全量重写或引入常驻 worker。
- 证据包保留精确源码行与明确省略信息。模型视图去重路径、修订信息，程序内部完整值与精确原文恢复保持不变。超长行不会阻止后续可容纳的实现和测试证据进入结果。
- 文档读取自动选择 DOCX、PDF、CSV、TSV 读取器，显示部分成功、嵌套文件错误及尚未读取的范围。
- 同聊天、同根目录的证据经当前文件修订核验后可以复用。工作集恢复提供有效正文与待核验事项，不假定模型仍保有旧上下文。等价路径采用一致身份比较，原生授权和修订检查仍保持有效。
- 原生命令输出按需直接显示状态、退出码或会话标识及诊断。已有测试、构建、差异和诊断摘要保持优先。插件不额外执行命令，也不绕开宿主审批。
- 成本记录区分模型外层调用、原生动作、内部 worker 启动、缓存与未缓存输入、有效证据及确实交付的自动分析。宿主转发明确来源标记时区分生产和验收；未知聊天身份不进行猜测。

新增 Rust 内核测量40个生产函数，CRAP最高5.0042867，超过6为0。使用 Lizard 圈复杂度与真实 LLVM 行、代码区域覆盖率中的较低值；不声称稳定编译器已提供分支或MC/DC覆盖。10项Rust单元测试、8项原生Python集成测试通过。未修改的上游crate和已有启动器shim不属于本次新增Rust覆盖测量范围。[Rust记录](../verification/rust-quality/latest.json)

15项原生传输与Code Mode场景通过。新的组合验收绑定最终Python源码、全部36个暂存运行文件和Rust内核二进制，验证长命令失败、轮询、工作流直接交付、带有新修订的变更文件证据及原始值精确恢复。早期单项记录保留各自源码版本的历史范围。[当前原生记录](../verification/v080-native-friction-current.json)

对0.6.1要求原生动作减少25%、输入减少20%，两项都未达到；未缓存输入有所下降，但严格质量不回退也未通过。原始通过数为0.6.1的33/36、0.7的45/48、0.8的43/48，包含每组各3次终端包装器失败。预先登记、修正包装器后的独立补充测试9/9通过，不替换或并入原132次结果。0.8另有两次日志答案把正文填入要求整数5001的line字段；交付证据实际包含5001，仍按固定判定保留失败。

0.8显式工作流采用26/48（54.17%），0.7为22/48（45.83%）。0.8在3/48任务中观测到自动交付，合并覆盖29/48（60.42%）；12次仅保存事件不计服务。在同一旧任务集上，0.8为19/36（52.78%），0.6.1为8/36（22.22%）。证据结构计数不等于任务成功；旧版本没有对应自动交付插桩，不能把未观测当作零。这些是基准采用率，真实日常采用率仍未知。

剩余开销来自实际调用路径：纯中文问题可能返回needs_anchor，领域词不在源码中时返回no_match；即便已有同次发现并调用的提示，模型仍会单独发现工具。小任务原本只需两次调用且输出很短，压缩收益有限；模型合并原生命令的方式也存在波动。另有三版本共同继承的诊断来源路径解析错误：错误前缀被当作文件路径的一部分，源码哈希完全相同。它与新工作流仅自动提取英文锚点的缺口是两个问题，也不能直接断言它造成line字段失败。[轨迹审计](../verification/v080-full-provisional-delivery-audit.md)、[失败审计](../verification/v080-failure-audit-late-log-2.json)

试跑、筛选、全量和补充结果分别保留；筛选阶段收益没有在全量达到门槛。无效试跑消耗及失败记录未删除，0.7曾获例外不自动延续。下一步可选择继续优化，或明确接受未达门槛后实验启用并保留回退；本次尚未选择或执行安装。

## 安装与回退

`scripts/package_local_plugin.py` 默认仅检查门槛，明确传入 `--build` 才创建不可覆盖的个人插件描述包。`tests/install_v080.py --check` 仅执行预检；明确传入 `--install` 才晋级已验收源码、调用原生插件安装、核对缓存字节、通过原生配置登记两项已核对hook的信任状态，并选择已验收运行时。

继续使用独立生产uv环境 `C:/Users/imsfp/.local/share/codex-runtimes/codex-ops-uv`，核对解释器、依赖版本和SQLite FTS5。新Rust内核二进制随已验收源码复制；不复制Rust构建目录或开发环境。插件描述包不含运行二进制、原始模型日志或私密配置备份。

晋级前保存带哈希的0.7源码ZIP、既有质量及桌面验收记录、marketplace/config备份和原运行时选择值；保留不可变的0.7运行目录与插件缓存。`rollback-0.8.0.json` 记录备份位置和新增源码文件。完整回退需要恢复源码、插件与配置状态以及选择值；只切换运行时不会恢复MCP源码。恢复前须核对当前状态，避免覆盖之后无关的配置修改。

安装后在真实重启验证前保持 `activeDesktopVerified=false`。配置指向0.8不等于当前桌面进程已加载0.8。安装器不会伪造沙箱就绪记录，也不会修改安全模式。
