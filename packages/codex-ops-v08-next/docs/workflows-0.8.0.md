# Codex Ops 0.8 workflow contracts

[中文](workflows-0.8.0.zh-CN.md). Commands, approvals, writes and polling retain the native Codex authority chain. The public MCP surface still has eight tools.

## Direct investigation

Call `ops_workflow({root:"C:/project",question:"Where is retry_delay capped and tested?"})`.
Optional `args` contains anchors, paths, focus and maxBytes (4096..24576).
Focus changes the bounded plan. Test/configuration clues add corresponding roles for
directory scopes; explicit file paths do not expand into sibling files.
The candidate-only Rust kernel reuses the existing dsh-ops core for one compound
read-only request. Ordinary file operations continue to use the existing worker.

Results retain exact selected source lines, revisions, coverage and pending stages.
Model-only views normalize file metadata and prioritize failures and omissions.
They carry an exact original-emission reference when projected; complete program
values are unchanged. A useful view does not need a raw retrieval.

## Documents and native results

`operation:"documents",args:{requests:[{operation:"read",args:{files:[{path:"policy.docx"}]}}]}`
routes DOCX/PDF/CSV/TSV to typed readers. Plain text ranges remain unchanged.
Independent native requests retain the existing bounded batch contract. Mixed
successes and nested file errors are visible before optional excerpts.

Large native command chunks preserve exit/session state and receive diagnostic
evidence without executing a new command or requiring a verify call. Existing
test/build/TypeScript/diff/source/media handling takes precedence where applicable.
Explicit `verify` still analyzes supplied observations; the optional SDK can
combine native execution and bounded polling.

## Automatic source recovery

Successful investigations save source evidence for the native chat, permission
context and root. `operation:"working_set",args:{action:"resume"}` recovers the
latest automatic set without a manual save/reference step. An explicit workingSetRef
continues to select a manually saved set.

Each file's selected lines have their own observation. Recovery reauthorizes refs
and checks revisions; stale files do not leak old lines into a different current
file's display. There is no assumed retention of model conversation context.

For a changed file, that same native check returns a fresh window around the saved
source lines, with two context lines and a maximum of 64 lines (a bounded head when
locations are unknown). `currentEvidence` has its own current revision; the old
snapshot stays marked stale. This is a selected window, not a refreshed whole-file
claim. If the packet budget omits it, `currentEvidenceRef` retains the fresh result
for exact retrieval without reading the file again. Saved availability is displayed
as available for later use; current evidence can be used immediately.

An exact repeated query over explicitly scoped files may reuse observations after
one native revision-read batch. Directory searches always run again so new files
can be discovered. Unknown chat identities do not enable automatic cross-call
recovery. Existing store TTL and quota apply; unavailable memory does not prevent a
fresh investigation from returning its evidence.

## Measurement

ops_stats accepts timezone-aware since/until and native turn_id. Actual chat tokens
are distinct from version/origin-scoped workflow and worker ledger events. Native
actions, outer calls and worker starts are separate boundaries. Completed calls,
useful evidence and independently labelled opportunities are different counts.

Automatic delivered diagnosis and automatic evidence reuse are reported separately
from explicit workflow selection. Unknown adoption remains unknown. Dropped-event
and retention limitations stay visible; ledger counters are not a net-savings
claim. Paired model comparisons must include failures, cached/uncached input and
actual on-demand plugin/hook/skill conditions.

The standalone Rust kernel adds no shell executor and no persistent daemon.
Existing source references remain scoped; no old authorization is restored.
