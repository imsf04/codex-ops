Basic investigation, document and log calls are specified by the active tool
guidance. Invoke the installed MCP entry within one functions.exec, keeping the
result in the same program:

```javascript
const result = await tools.mcp__codex_ops__ops_workflow({root:"ABSOLUTE_ROOT",question:"code question"});
text(result);
```

Use source evidence to finish when it answers the task. A workingSet state of
saved confirms later recovery is available. Resume later or after sources change;
current-read evidence is newly observed and has its own revision and coverage.
Stale saved content does not become current. Add args.anchors for ambiguous terms
or args.paths to narrow investigation. Partial source coverage and omitted rows
identify the specific evidence still missing.

Keep complete values inside functions.exec. Print the needed result normally;
automatic compression preserves raw values and native exit/session state.
Use ops_result(view="raw") with nextOffset only for missing exact content.
Do not rerun a producer to recover its displayed output.

Single known reads, writes and polling stay native with explicit workdir.
For exact comparisons and staged changes, read [advanced contracts](references/advanced.md).
For SDK composition or operation-specific options, ops_catalog("workflows")
provides contracts and the optional Code Mode SDK. verify analyzes existing native
chunks; execution and approvals remain with Codex.
ops_stats separates real usage, useful evidence and worker calls from display bytes;
unknown eligible-opportunity adoption is not zero or a percentage.
