# 证据摘要与同帧预算

0.6 的呈现层保留程序内部原始值和逐字节可取回的输出文字。已完成的 shell
结果可以展示有界的 TypeScript/构建诊断、Python/pytest 失败、Git diff
修改证据和 Git 短状态路径。摘要包含行号、结束统计、源代码位置，以及省略
诊断和行数。它是证据样本，不证明未显示部分没有其他错误；源代码中出现
错误字符串，也不会让整段代码被当成日志。

带名称、标题或状态的常见 JSON 列表提供有界记录样本，并保留已有标识与路径。失败记录即使
出现在列表后部，也优先显示。计数只描述已保存的观察结果，不代表上游服务的
全局总数。凭回执中的 `ops://` 引用仍可取回精确原文。

同一个 Code Mode 出站帧包含多段文字且合计超过 12 KiB 时，各段按占比分配
呈现目标。因此，单段未达到普通阈值的输出也不会无限堆积。该目标是软预算：
明确取回页、媒体和原生错误状态保留各自契约；没有压缩收益或存储不可用时
保留原文。每次替换必须节省字节，JavaScript 内部的工具返回值保持不变。
同帧预算仅在普通回执超过分配目标时进一步收紧，绝不把已有较小回执替换为更大的预览。
相同文字仅在同一个执行结果帧内复用引用，不因为先前模型步骤出现过就省略。

真实命令对照见 `verification/v06-evidence-benchmark.json`。更有用的摘要可能
比通用摘要更长：Git diff 案例保留了更多修改证据。字节减少本身不证明模型
token 更少、后续回读更少或任务更快。
