# 0.6 范围与原版对照

原版源码参照本机 dsh-ops `61ef553`（2026-10-27），公开集成契约同时核对上游文档。
适配器复用原版 Rust worker；同等 worker 能力属于复用，不代表独立实现超过原版。

| 方向 | 已实现接口 | 保留边界 |
| --- | --- | --- |
| 组合工作流 | 定位、诊断、文档证据、增量读取；可执行 JS helper 与参数类型；原生命令串接诊断 | 显式 helper，并非桌面原生动态注册；命令保留原生权限。 |
| 有用的证据 | 测试/构建/编译诊断、Git diff/status 与 MCP 列表摘要；完整原文引用 | 使用明确支持的确定性规则，不熟悉的结果沿用通用展示。 |
| 增量与整组预算 | 按归属、根目录和范围绑定的基线比较；同一输出帧共享预算 | 不假设旧内容仍在模型上下文；明确回读、媒体和不可缩减文字可超出软预算。 |
| 原生任务 | 顺序阶段、文件与有界目录、状态/取消/恢复/回滚、中断恢复 | 日志不构成原子事务；Windows 原生策略仍可拒绝元数据发布。 |
| 隔离与安装 | MCP 引用绑定聊天/权限；自动引用绑定运行时；当前进程版本核对与只读面板 | 运行时身份不等于聊天身份；不防同系统用户的恶意客户端；没有原生 Codex 侧栏。 |
| 评测 | 20 项不同任务、两次重复、原生/0.5/0.6；原生独立校验；保留失败 | 等价注入 skill/hook 指引，不声称每次实际触发 hook；条件不可比时不宣称超过 DSH 效率。 |

正确性、完整原始值、诊断、现有权限与 CRAP ≤6 是发布要求。调用减少 25%、输入 token
减少 20% 是测量目标，不能预先当作事实或发布结论。解释中位数前须记录回归与可比配对数；
缓存输入、非缓存输入和输出分别报告。原型或合计输出字节节省不等于 token 费用节省。

桌面集成由原生本机插件接口与明确验证版本的 Code Mode 桥接共同构成，不修改 OpenAI
二进制或模型流量。未知 host 版本保持透传；宿主升级后须重新验证。
